# Luna Family Finance Dashboard — Live Demo

Static UI demo of the LFFD single-page dashboard. **All data is fabricated sample
data** (see `demo.json`) — no real accounts, balances, or transactions.

This is a front-end preview only. The real app is a FastAPI + SQLite service that
runs locally; GitHub Pages is static so it cannot run the backend.

Source (private): the main `finance-tracker` repo.
